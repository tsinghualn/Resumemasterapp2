## Implementation Pattern

### Common Helper Functions

All variety files should include these helper functions:

```typescript
const renderBulletContent = (line: string, isExperienceType: boolean) => {
  if (isExperienceType && (line.startsWith('•') || line.startsWith('-') || line.startsWith('→'))) {
    return { isBullet: true, content: line.substring(1).trim() };
  }
  return { isBullet: false, content: line };
};

const renderJobTitle = (line: string, isExperienceType: boolean) => {
  if (isExperienceType && line.includes('|')) {
    const [title, rest] = line.split('|');
    return { isTitle: true, title: title.trim(), details: rest.trim() };
  }
  return { isTitle: false, content: line };
};
```

### Section Type Detection

```typescript
const upper = sectionName.toUpperCase();

// Sidebar sections
const isSidebarSection = upper.includes('SKILL') || upper.includes('COMPETENC') || 
                         upper.includes('EDUCATION') || upper.includes('ACADEMIC') || 
                         upper.includes('CERTIFICATION') || upper.includes('LICENSE') ||
                         upper.includes('LANGUAGE') || upper.includes('AWARD') || upper.includes('HONOR');

// Main content sections
const isMainSection = upper.includes('SUMMARY') || upper.includes('PROFILE') || upper.includes('OBJECTIVE') ||
                     upper.includes('EXPERIENCE') || upper.includes('EMPLOYMENT') || upper.includes('PROJECT');

// Experience-type sections (need bullet/title parsing)
const isExperienceType = upper.includes('EXPERIENCE') || upper.includes('EMPLOYMENT') || upper.includes('PROJECT');
```

### Standard Structure for Each Variety

```typescript
if (variety === X) {
  return (
    <div className="bg-white" style={{ width: '8.5in', minHeight: '11in', margin: '0 auto' }}>
      {/* Header with name and contact */}
      <div className="header-styling">
        <h1>{parsedData.name || 'Your Name'}</h1>
        <div className="contact-info">
          {parsedData.contact.email && <span>{parsedData.contact.email}</span>}
          {parsedData.contact.phone && <span>{parsedData.contact.phone}</span>}
          {parsedData.contact.details && <span>{parsedData.contact.details}</span>}
        </div>
      </div>

      {/* Dynamic section rendering */}
      {Object.entries(parsedData.sections).map(([sectionName, sectionContent]: [string, any]) => {
        const upper = sectionName.toUpperCase();
        const isExperienceType = upper.includes('EXPERIENCE') || upper.includes('EMPLOYMENT') || upper.includes('PROJECT');
        
        return (
          <div key={sectionName} className="section-styling">
            <h2 className="section-header">{sectionName.toUpperCase()}</h2>
            <div className="section-content">
              {sectionContent.map((line: string, idx: number) => {
                const bullet = renderBulletContent(line, isExperienceType);
                const title = renderJobTitle(line, isExperienceType);
                
                if (bullet.isBullet) {
                  return <div key={idx}>• {bullet.content}</div>;
                }
                if (title.isTitle) {
                  return (
                    <div key={idx}>
                      <h3>{title.title}</h3>
                      <p>{title.details}</p>
                    </div>
                  );
                }
                return <p key={idx}>{line}</p>;
              })}
            </div>
          </div>
        );
      })}
    </div>
  );
}
```

## Layout Patterns Reference

### Single Column Layouts
- Full width content, top to bottom
- Variations: header position, spacing, borders
- Use for: ATS compliance, simple formats
- Examples: ATS 1, 2, 8, 9, 10

### Two Column Equal Split
- 50/50 column division
- Variations: which sections go where
- Use for: balanced presentation
- Examples: ATS 4, Executive 2, Minimal 2

### Sidebar Layouts
- **Left Sidebar**: Narrow left (1/3-1/4) + wide right (2/3-3/4)
  - Sidebar: Skills, Education, Certifications, Languages
  - Main: Summary, Experience, Projects
  - Examples: ATS 3, Executive 1, Modern 1

- **Right Sidebar**: Wide left (2/3-3/4) + narrow right (1/3-1/4)
  - Mirrored version of left sidebar
  - Examples: ATS 6, Executive 3, Modern 2

### Three Column Layouts
- Equal or varied column widths
- For maximum content density
- Examples: ATS 7

### Timeline Layouts
- Vertical timeline for experience
- Dots/markers for jobs
- Connecting lines
- Examples: ATS 5

### Grid Layouts
- CSS Grid for flexible arrangements
- Sections can span different areas
- Examples: Modern 8, 12, 18

### Banner/Header Bar Layouts
- Large colored header across top
- Single column content below
- Examples: Modern 4, Creative 3

### Boxed/Card Layouts
- Each section in its own box
- Shadows and borders
- Examples: Creative 2, ATS 9

## Color Scheme Guidelines

### ATS Templates
- **Primary**: Grays (gray-50 to gray-900)
- **Accent**: Black for important elements
- **Background**: White or gray-50/gray-100
- **Text**: gray-700 to gray-900

### Executive Templates
- **Primary**: Slate, charcoal, navy
- **Accents**: Professional blues, deep colors
- **Background**: White with colored sidebars/headers
- **Text**: Mostly black/dark gray

### Modern Templates
- **Primary**: Full color range (blue, teal, purple, orange, green, etc.)
- **Gradients**: from-{color}-600 to-{color}-800
- **Background**: White main, colored sidebars
- **Text**: Dark gray with colored accents

### Creative Templates
- **Primary**: Bright gradients
- **Gradients**: Multi-color (from-X via-Y to-Z)
- **Background**: Can be colored or gradient
- **Text**: Dark with gradient headings (bg-clip-text)

### Minimalist Templates
- **Primary**: Grays (gray-300 to gray-600)
- **Accents**: Thin lines, subtle bars
- **Background**: Pure white
- **Text**: Light to medium grays
